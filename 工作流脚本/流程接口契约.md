# 标准模式接口契约

调用接口：`POST /api/workflow/run`

```json
{
  "project": "原创-作品名",
  "task": "compile_anchor",
  "inputMode": "structured",
  "inputComplete": false,
  "input": {},
  "naturalInput": ""
}
```

`inputMode=structured` 时传入 `input` JSON；`inputMode=natural` 时传入 `naturalInput`。自然语言和 `inputComplete=false` 的结构化输入，都会由当前步骤在 `LLM配置.py` 中配置的 LLM 整理、补全和润色后再执行。只有用户明确填写完整并设置 `inputComplete=true` 时，确定性模板步骤可直接使用字段；内容生成步骤仍调用自己的 LLM。模型配置不由前端请求指定。

| task | 业务脚本 | 必填 input | 产物 |
| --- | --- | --- | --- |
| `text_stats` | 提取文本统计 | `source` | `提取/原文统计.txt` |
| `word_frequency` | 提取高频词 | `source` | `提取/高频词.txt` |
| `style` | 提取文风 | `source` | `提取/原文风格.md` |
| `positive_vocabulary` | 提取正向词库 | `source` | `提取/正向词库.md` |
| `exclusive_vocabulary` | 提取专属词库 | `source` | `提取/专属词库.md` |
| `generate_worldview` | 生成世界观 | 世界观字段 | `知识库/世界观.md` |
| `compile_style` | 生成语言风格 | 至少一个风格字段 | `知识库/语言风格.md` |
| `generate_character` | 生成角色卡 | `name` 与角色字段 | `知识库/角色卡/角色卡-<名>.md` |
| `compile_relation` | 生成关系卡 | `character_a`、`character_b` | `知识库/关系卡/关系卡-<A>-<B>.md` |
| `compile_plot` | 生成剧情规划 | `kind`、剧情字段 | `剧情/剧情书.md` 或 `剧情/剧情卷/<卷>.md` |
| `compile_ledger` | 生成信息账本 | `entries` | `知识库/信息账本.md` |
| `compile_anchor` | 生成强制设定锚点 | `chapter`、`characters`、`core_event` | `提示词/<章>/强制设定锚点.md` |
| `compile_config` | 生成章节配置 | `chapter`、至少一个配置字段 | `提示词/<章>/配置.md` |
| `compile_dialogue` | 生成台词 | `chapter`、`dialogues[]` | `提示词/<章>/台词.md` |
| `compile_snapshot` | 编译提示词快照 | `chapter` | `提示词/<章>/最终提示词快照.md` |
| `generate_prose` | 生成章节正文 | `chapter` | `正文/<章>.txt` |
| `rewrite_prose` | 改写章节正文 | `chapter`、`instruction` | `草稿/<章>-改写预览.txt` |
| `validate` | 校验章节正文 | `chapter` | `提示词/<章>/校验报告.md` |

没有登记 `原文向量索引`，也没有登记正文后的资产增量更新任务；它们不属于当前版本范围。

## 格式门禁

每个任务在写入正式产物前，都会按《完整流程与选择规范.md》检查对应的标题、必填字段或区段：例如角色卡的身份/性格/外貌/语言习惯/年龄，关系卡的五个关系字段，锚点的五项内容，快照的固定上下文区段，以及校验报告的语义校验和结论。格式不通过时不会覆盖正式资产，接口返回错误。

`compile_config` 只能使用右侧“配置｜选择式编辑”中提供的十组枚举值。后端会拒绝不在选项内的值，并始终输出全部十个分组；未选择的分组留空。`compile_snapshot` 固定汇总世界观、语言风格、本章涉及角色卡与关系卡、锚点、配置、台词、禁词表、通用词库和上一章结尾；禁词表与通用词库的固定路径为 `知识库/禁词表.md`、`知识库/通用词库.md`，不存在时快照明确写为“无”。

## 锚点示例

```json
{
  "chapter": "第3章：旧码头",
  "characters": ["沈栖迟（戒备）", "陆闻洲（克制）"],
  "core_event": "陆闻洲在旧码头交出一封旧信。",
  "information_boundary": "不公开寄件人身份。",
  "foreshadowing": "信封上的盐渍。",
  "hook": "信封背面有沈栖迟的名字。"
}
```
