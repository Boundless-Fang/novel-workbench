# Skill: novel-init-project（小说项目目录自检/初始化）

## 用途
在动笔写小说之前，确保项目目录结构齐全：检查 + 缺失补齐。

## 触发条件
- 用户开始一本新小说，还没有项目文件夹
- 用户要求"新建项目 / 建文件夹 / 检查目录 / 目录自检"
- 任一小说写作流程开始前，尚未确认项目目录

## 目录规范（本 skill 保证）
```
<根>/<原创|同人>-<作品名>/
  ├─ 提示词/<章>/<章>大纲.md、<章>台本.md、<章>校验报告.md
  ├─ 知识库/世界观卡.md、知识库/角色卡/<角色>.md
  ├─ 原著/            # 同人参考原著；原创可空
  └─ 正文/<章>.txt
```

## 根目录判定
1. 用户显式给出项目根目录时以用户为准；
2. 当前工作目录就是小说项目根（同时含 `知识库`/`提示词` 标志，或目录名含"小说项目"、或含 `原创-*`/`同人-*` 项目）——处理"对话所在文件夹就是小说项目"的情况；
3. 否则默认在当前工作根下建 `小说项目/` 作为项目根。

## 运行方式
用持久 shell 创建缺失的目录与文件，不覆盖已有内容：
```powershell
New-Item -ItemType Directory -Force -Path `
  "<项目>/提示词/<章>","<项目>/知识库/角色卡","<项目>/原著","<项目>/正文"
```
- 只补缺，不重建：已存在的世界观卡/角色卡保持原样。

## 判断原创/同人
- **原创**：作品是作者原创故事（无原 IP）→ `原创-作品名`
- **同人**：基于已有作品/世界观/角色二次创作 → `同人-作品名`
- 用户没明说时，先问一句或按用户描述判断；不确定默认按用户叙述倾向。

## 检查（必做）
- [ ] 项目根判定正确（对话所在文件夹是项目时以当前目录为根）
- [ ] 作品文件夹名带 `原创-`/`同人-` 前缀且与判断一致
- [ ] 四子目录 `提示词/ 知识库/ 原著/ 正文/` 齐全
- [ ] `知识库/世界观卡.md` 与 `知识库/角色卡/` 已创建
- [ ] 未误删/覆盖已有文件

## 失败处理
- 根目录判断错误：向用户确认后显式指定项目根，重跑本 skill。
