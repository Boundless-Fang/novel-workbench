# Skill: novel-normal-stage3-script（③ 台词 / 台本）

## 用途
普通小说流程的 ③ 环节：依据大纲与角色卡生成《第X章台本》。

## 触发条件
- ② 环节已通过检查（`提示词/<章>/第X章大纲.md` 存在）；
- 且需要生成本章台本（`提示词/<章>/第X章台本.md` 不存在或检查未通过）。

## 输入
- 公共输入中本环节使用的部分：锚点、角色卡（novel-normal skill《公共输入》）。
- `提示词/<章>/第X章大纲.md`（② 产物，缺失则先回 ② 重做）
- `提示词/普通/对话词库.md`
- `提示词/普通/语言风格.txt`

## 输出（固定路径）
- `提示词/<章>/第X章台本.md`

## 处理
- 依据大纲与角色卡逐场景展开，用文件编辑工具直接产出《第X章台本》。
- 生成模型与思考档见 novel-conventions skill《通用约定·模型》。
- 产出台本时：每条台词＝角色 + （神态/动作/心理[]）+ “台词……” + **[取材：对话词库·×××]**。

## 检查（必做，检查模型见 novel-conventions skill）
- [ ] 称呼与《强制设定锚点》一致（禁止无区分或与关系不符的称呼）
- [ ] 每条台词末尾有独立 `[取材：对话词库·×××]`
- [ ] 覆盖大纲全部对话场景
- [ ] 潜台词不被角色直白点破（角色不把对方未说出口的情绪/动机直接说出来）
- [ ] 对话通俗、符合人设；未展开与情节无关的知识性讨论

## 失败处理
- 只重做本环节；问题记录到 `提示词/<章>/第X章校验报告.md`。
