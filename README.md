# 小说工作台

一个本地运行的长篇小说 AI 创作辅助工具：把初始化资料、世界观、角色卡、剧情、章节正文和校验报告组织成可追溯的本地项目，并用 LLM 按步骤生成正式资产。

## 功能特性

- 原创 / 同人项目，本地文件存储。
- 同人原著上传与五步提取。
- 初始化流程：小说简介、世界观、语言风格、角色名单、角色卡、关系卡、剧情书、剧情卷、信息账本。
- 章节流程：锚点 → 配置 → 台词 → 最终提示词快照 → 正文 → 校验与验收。
- 顶部“可更新”区支持全局资产一键生成/更新。
- 撤回 / 重试 / 下一步。
- 自动模式：初始化与章节流程可自动连续执行。
- 失败卡片显示模型、token、耗时；校验类失败显示“校验未通过”。
- 项目累计输入/输出用量统计与持久化。

## 快速开始

### 1. 环境要求

- Node.js（建议 18+）
- Python 3.11 或 3.12
- 一个 OpenAI 兼容的 LLM API（DeepSeek、硅基流动、OpenAI、Kimi、GLM 等）

### 2. 启动服务

#### 一键启动（推荐）

Windows 双击：

```text
启动工作台.bat
```

macOS / Linux / Git Bash：

```bash
./启动工作台.sh
```

启动器会自动打开浏览器：`http://127.0.0.1:4173`

#### 手动启动

```bash
cd web
node server.mjs
```

浏览器打开：

```text
http://127.0.0.1:4173
```

### 3. 配置模型

在页面左下角“设置”中填写提供方、API 地址、API Key 和模型，或在顶部模型控件中快速切换。

配置保存在：

```text
工作流脚本/工作台设置.json
```

## 目录结构

```text
小说生成全流程/
├─ 启动工作台.bat       # Windows 一键启动
├─ 启动工作台.sh        # macOS / Linux / Git Bash 一键启动
├─ web/                 # 前端 + Node 本地服务
├─ 工作流脚本/          # Python 工作流引擎与步骤模块
├─ docs/                # PRD、技术文档、流程规范
└─ 小说项目/            # 所有本地小说项目
```

详细文件职责见 [docs/技术文档.md](docs/技术文档.md)。

## 使用流程

1. 新建小说（原创或同人）。
2. 填写小说资料并完成初始化。
3. 新建章节，按步骤生成正文。
4. 校验与验收。
5. 使用顶部“可更新”随时更新世界观、角色卡、关系卡等全局资产。

## 测试

先启动服务：

```bash
cd web
node server.mjs
```

再运行验收：

```bash
# 无模型完整流程验证
python 工作流脚本/验证完整流程.py

# 端到端验收（默认不调用真实模型）
python 工作流脚本/验证工作台验收.py

# 真实模型验收（会消耗 API 额度）
python 工作流脚本/验证工作台验收.py --live-model
```

## 注意事项

- `工作台设置.json` 中可能包含 API Key，请勿提交到公开仓库。
- 每个小说项目是普通文件夹，建议用 Git 管理版本。
- 当前版本尚未实现“验收后资产增量更新”和 Git 自动提交。
