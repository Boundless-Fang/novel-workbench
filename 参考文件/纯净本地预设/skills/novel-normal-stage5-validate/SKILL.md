# Skill: novel-normal-stage5-validate（⑤ 校验与微调）

## 用途
普通小说流程的 ⑤ 环节：对本章产物做最终校验，输出《第X章校验报告》。

## 触发条件
- ④ 环节已通过检查（`正文/第X章.txt` 存在）；
- 且需要输出本章校验报告（`提示词/<章>/第X章校验报告.md` 不存在或需更新）。

## 输入
- 公共输入见 novel-normal skill《公共输入》（本环节需全部：锚点 + ① 产物）。
- 本章全部产物：`提示词/<章>/第X章大纲.md`、`第X章台本.md`、`正文/第X章.txt`
- `提示词/普通/校验提示词.md`（27 词）
- `提示词/普通/禁用词库.txt`

## 输出（固定路径）
- `提示词/<章>/第X章校验报告.md`

## 处理
- 用检查模型对全部产物做内容校验（锚点比对 / 设定一致性 / 大纲符合度 / 逻辑自洽 / 文风质量），用文件编辑工具写出报告。
- 报告至少包含：锚点比对 / 设定一致性 / 大纲符合度 / 逻辑自洽 / 文风质量（27词+禁用词）/ 结论与修改建议。
- 文风质量另加一节“SLOP 评分”：用 `novel-slop` 六类三级词表 + 计分公式给出 score（0-10）、评级、Top 扣分点与重复率。
- 字数等基础指标可用持久 shell 统计作二次参考，不能替代 LLM 内容校验。

## 检查（必做，检查模型见 novel-conventions skill）
- [ ] 报告本身包含上述全部维度
- [ ] 锚点比对逐条列出（称呼/关系/核心事件/行为边界）
- [ ] 结论明确 PASS / 需修改，且修改建议给出替代写法
- [ ] 若结论为“需修改”，回到对应环节重做，本报告保留问题记录
- [ ] “SLOP 评分”节含 score / 评级 / Top 扣分点 / 重复率

## 失败处理
- 若报告缺维度或结论不明确，重做本环节；若报告指出上游问题，转对应 stage 重做。
