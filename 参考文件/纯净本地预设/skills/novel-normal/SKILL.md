# Skill: novel-normal

## 用途
普通小说生成流程。当用户需要生成不涉及情欲/NTR 内容的正常小说时，调用本 skill。

## 触发条件与适用判断
- 用户要求“生成普通小说 / 不写H / 清水 / 日常恋爱 / 冒险 / 玄幻 / 都市”等，且未明确要求情欲/NTR 内容
- 题材为普通恋爱、日常、冒险、玄幻、都市等，不包含露骨情色描写
- 用户提到 `novel-normal`、`普通模式`、`按流程生成一章`
- 输入包含世界观/角色/本章剧情，需要跑 ①→⑤ 全流程

## 项目目录自检（动笔前必做）
1. 先检查项目目录是否存在（判定规则见 novel-init-project skill《根目录判定》）。
2. 缺失则判断作品是**原创**还是**同人**，调用 **`novel-init-project`** skill 创建；目录结构与章节文件命名以该 skill《目录规范》为准。

## 流程（按顺序调用独立 stage skill）
1. **`novel-normal-stage1-worldview`** —— ① 世界观-信息卡 → `知识库/世界观卡.md`、`知识库/角色卡/*.md`
2. **`novel-normal-stage2-outline`** —— ② 本章大纲 → `提示词/<章>/第X章大纲.md`
3. **`novel-normal-stage3-script`** —— ③ 台本 → `提示词/<章>/第X章台本.md`
4. **`novel-normal-stage4-prose`** —— ④ 正文 → `正文/第X章.txt`
5. **`novel-normal-stage5-validate`** —— ⑤ 校验 → `提示词/<章>/第X章校验报告.md`

每个 stage 都是独立 skill，按上面的 skill 名依次调用。

## 公共输入（各 stage 默认携带，stage 文件不再重复列出）
- `知识库/强制设定锚点.md`：所有环节必读；
- ① 产物 `知识库/世界观卡.md`、`知识库/角色卡/*.md`：② 大纲、④ 正文、⑤ 校验使用。

## 共享锚点（所有环节必读）
- 项目级：`<项目>/知识库/强制设定锚点.md`
- 模板：`shared/强制设定锚点.md`
- 缺失时先按模板生成并填充，再进入任何 stage。

## 可选前置
- 同人项目要求模仿原作风格/用词：先调用 `novel-extract-source`，把产物写入 `<项目>/知识库/原文信息/`。
- 需要从参考原文或已写章节里取片段：调用 `novel-search`（检索小说原文，不是词库）。

## 每环节强制检查
- 每个 stage 完成后，必须按该 stage SKILL.md 的“检查”清单执行；
- 检查模型与思考档见 novel-conventions skill《通用约定·模型》；
- 未通过 → 只重做当前环节，不重跑全流程。

## 执行方式
- 各环节均为独立 skill，按上面 skill 名依次调用；
- 优先用 `脚本/novel_flow.py` 执行各环节（规则见 novel-conventions skill《通用说明》）；脚本不可用时用文件编辑工具与持久 shell 手工完成。

## 约束
- 不加载 `人物词库补充.md`、`对话词库补充.md`、`通用词库补充.md`
- 不读取 `ntl小说的关键要素.txt`
- 校验使用 `提示词/普通/校验提示词.md`
