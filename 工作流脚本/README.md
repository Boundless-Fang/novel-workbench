# 小说工作台工作流脚本

这里不再保留按步骤命名的一行式入口文件。Web 和命令行只调用 `工作流引擎.py`；引擎按 `步骤定义.py` 找到真正的业务模块。

```text
工作流引擎.py  输入解析、依赖/必填校验、步骤调度、失败记录
步骤定义.py    输入字段、步骤归属、完整流程产物格式规则
LLM配置.py     每步骤的模型/API/温度配置
共享.py        项目路径、文件写入、格式门禁、同人提取脚本适配
资产步骤.py    世界观、语言风格、角色卡、关系卡、剧情、账本
章节步骤.py    锚点、配置、台词、大纲、快照、正文、改写
提取步骤.py    原文统计、词频、文风、词库
校验步骤.py    正文的 LLM 语义验收
```

步骤模块不是目录别名：每个模块负责其产物的上下文选择、LLM/参考脚本调用、落盘路径以及格式契约。`共享.py` 的 `checked_write` 会在写入正式资产前按《完整流程与选择规范.md》检查标题、必填段落、表格或台词格式；不通过则不写入正式产物。

所有脚本均支持两种输入：

- 结构化：`--project <项目目录名> --input_mode structured --input '<JSON>'`
- 自然语言：`--project <项目目录名> --input_mode natural --natural_input '<用户文本>'`

自然语言和未填完整的结构化输入，都会发送给当前步骤在 `LLM配置.py` 中指定的 LLM：前者用于提取字段，后者用于保留已填内容、补齐空缺并润色表达。所有生成型步骤均由该步骤 LLM 生成最终资产；`--input_complete` 只允许配置等确定性表单步骤直接落盘。最终提示词快照始终按已确认资产确定性冻结，不经过 LLM 改写。模型、温度、超时和 API 配置统一由 `LLM配置.py` 控制，调用方不能临时覆盖步骤模型。

缺少必填字段时，脚本会写入 `<项目>/运行记录/待补充/<任务>.json`，当前版本不发起反问，也不会写入正式产物。

## 结构化世界观 JSON（已接入 Web）

`世界观JSON.py` 生成 `知识库/世界观.json`，不再经过 Markdown 标题校验；只保证 LLM 返回 JSON 对象即可落盘。

- 工作流任务：`generate_worldview_json`
- 网页初始化阶段：`世界观 JSON`
- 下游章节锚点、快照、正文上下文、校验已兼容 `世界观.json`（优先读 `世界观.md`，没有时读 JSON）

独立命令行仍可用：

```bash
python 世界观JSON.py --project 原创-作品名 --input_mode natural --natural_input "东方玄幻，宗门林立……"
python 世界观JSON.py --project 原创-作品名 --mock   # 不调用 LLM，先试流程
```

## 产物规则

目录与命名以 `完整流程与选择规范.md` 为准。同人提取代码在 `同人提取/` 内隔离运行，文风评分代码在 `文风评分/` 内运行，产物会回写到当前小说项目中；这些代码已并入本工作台，不再依赖外部 `StyleSync-Novel` / `Inkflow` 目录。
