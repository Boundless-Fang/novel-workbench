# Skill: novel-normal-stage1-worldview（① 世界观-信息卡）

## 用途
普通小说流程的 ① 环节：生成《世界观设定卡》与逐角色《角色信息卡》。

## 触发条件
- 已确认普通模式（novel-normal），项目已 `init`；
- 且 `知识库/世界观卡.md` 或 `知识库/角色卡/*.md` 尚未生成；
- 或 ① 环节检查未通过，需重跑本环节。

## 输入
- 公共输入见 novel-normal skill《公共输入》（本环节仅需锚点）。
- 用户总纲原文（文件或粘贴文本）
- `提示词/普通/总纲与信息卡.txt`
- `提示词/普通/人物词库.md`

## 输出（固定路径）
- `知识库/世界观卡.md`
- `知识库/角色卡/<角色名>.md`（每角色一个文件）

## 处理
- 依据用户总纲与 `提示词/普通/总纲与信息卡.txt` 的要求，用文件编辑工具直接产出世界观卡与角色卡。
- 生成模型与思考档见 novel-conventions skill《通用约定·模型》；可在项目配置中覆盖。
- 产出后先按《强制设定锚点》逐条核对，再进入检查。

## 检查（必做，检查模型见 novel-conventions skill）
用检查模型对产物做检查：
- [ ] 称呼锚点齐全，与 `强制设定锚点.md` 一致（爱称/关系称呼不缺失、不冲突）
- [ ] 重要性分级与用户设定一致（1路人/2配角/3重要/4主角）
- [ ] 女角色称谓指代≥3；雅称美称来自 `人物词库.md`，非凭空推演
- [ ] 缺失且无法推断的项标注（推演补全）
- [ ] 关键历史按时间线且不可改写
- [ ] 输出路径与命名规范一致

## 失败处理
- 记录检查发现的问题；只重跑本环节，不重跑后续环节。
